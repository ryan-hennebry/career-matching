# Presentation rules

Use the validated manifest to determine which roles to show. Show up to ten roles in the main list. Give the exact title, company, link, action tier, source and date checked. In plain language, explain the central work, the strongest evidence and the main concern. Use a label for provisional sources and unknown age.

Keep optional actions and overflow in the appendix. Tell the candidate how many roles remain pending and name blocked or capped sources. If the result has zero recommendations, state what the search covered.

Use a short table or list in chat and offer the local dashboard for details. The candidate decides whether to apply, request a brief or adjust the search. Keep their history and application materials in ignored local files.
